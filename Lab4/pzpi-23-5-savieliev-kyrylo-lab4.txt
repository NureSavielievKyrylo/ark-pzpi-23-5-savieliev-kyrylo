3 ОПИС ВИКОНАНОЇ РОБОТИ
Під час виконання лабораторної роботи було розроблено IoT клієнт «Вежа
дедлайнів».
Цей клієнт дозволяє відстежувати статуси рукописів та прогнозувати їх
завершення за допомогою різних методів аналізу даних, таких як матриця переходів
Маркова, виявлення аномалій активності, баєсівське передбачення та симуляція
Монте-Карло.
Приклад розрахунку баєсівського передбачення дедлайнів:
DeadlinePrediction BayesianPredictor::predict(
const ManuscriptData &manuscript,
float priorMeanDuration,
float priorStdDev)
{
DeadlinePrediction result;
strncpy(result.manuscriptId, manuscript.id,
sizeof(result.manuscriptId) - 1);
result.manuscriptId[sizeof(result.manuscriptId) - 1] = '\0';
strncpy(result.manuscriptName, manuscript.name,
sizeof(result.manuscriptName) - 1);
result.manuscriptName[sizeof(result.manuscriptName) - 1] = '\0';
int remainingStages = manuscript.totalStages manuscript.completedStages;
float expectedRemainingDays = estimateRemainingDays(manuscript,
priorMeanDuration);
result.expectedDaysRemaining = expectedRemainingDays;
if (strlen(manuscript.deadlineAt) == 0)
{
result.probabilityOnTime = 1.0f;
result.riskLevel = RISK_LOW;
return result;
}
float daysUntilDeadline =
Analytics::daysUntilDeadline(manuscript.deadlineAt);
if (daysUntilDeadline < 0)
{
result.probabilityOnTime = 0.0f;
result.riskLevel = RISK_CRITICAL;
return result;
}
if (remainingStages <= 0)
{
result.probabilityOnTime = 1.0f;
result.riskLevel = RISK_LOW;
return result;

4 ВИСНОВКИ
У ході виконання лабораторної роботи було розроблено IoT клієнт «Вежа
дедлайнів», який дозволяє відстежувати статуси рукописів та прогнозувати їх
завершення. Було створено UML діаграми прецедентів та діяльності (див. рис. Б.1Б.2), що відображають функціональні можливості клієнта.
Програмна реалізація бізнес логіки та функцій налаштування була успішно
виконана, і робота клієнта була перевірена на коректність. Розроблений IoT клієнт
може бути використаний для ефективного управління рукописами
